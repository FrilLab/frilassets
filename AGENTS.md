# Agent instructions

- This repository creates reusable 3D assets, not a production application.
- Read `docs/asset-layout.md` before creating an asset. Keep generation code, editable source, exports, previews and metadata together in a single asset directory.
- Work on a dedicated branch and do not modify FrilStudio or FrilCraft. Consult their modeling contracts read-only when relevant.
- Prefer Blender Python and standard glTF/GLB; do not introduce application frameworks or dependencies without approval.
- Inspect rendered output and validate dimensions, pivots, materials, geometry, file size and provenance before declaring an asset ready.
- Never include secrets, private client media, unlicensed references or third-party content without compatible rights. Only mark reviewed assets CC0. Do not publish to Sketchfab without approval.
- Keep public documentation in English. Do not claim unimplemented tools or unverified results.
