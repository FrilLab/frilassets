# Publication and licensing

Software and documentation retain the root MIT license. Only explicitly designated, rights-reviewed asset files are offered under CC0-1.0. Record the file scope in the manifest or a package-level license notice. Do not imply that CC0 clears third-party rights.

Check the actual AI tool terms and all third-party inputs before release. Record provenance, generation and editing details, and any restrictions. Do not publish private or uncleared material to a public branch. Draft status does not make a public commit private.

Before publication, review visual quality, technical checks, and rights; update the manifest with a real version, release status and explicit asset license. Preserve attribution and notices required by any non-CC0 dependencies; do not designate such files CC0 without authority.

Sketchfab is a proposed channel for 3D models. Confirm current platform license options, AI disclosure requirements and upload eligibility before manual publication. Use `templates/sketchfab.md` for model descriptions. Images, textures, and materials may be distributed via repository packages or releases; no external publishing integration is configured.

Large binaries may eventually use Git LFS or release storage; this change does not configure either.
